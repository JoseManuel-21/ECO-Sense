# Eco-Sense — Air Quality Monitoring System

## Overview

Eco-Sense is an intelligent air quality monitoring platform focused on collecting, processing, and visualizing environmental metrics in real time.

The project was developed as part of an academic innovation initiative and obtained 2nd Place at InnovaTec Morelia 2025.

---

## Features

- Real-time air quality monitoring
- Intelligent environmental data processing
- Dynamic data visualization
- Backend API integration
- Interactive analytics dashboards
- MongoDB data persistence
